# 🎬 Netflix Power BI Dashboard

## 📌 Project Overview
This project involves the development of an interactive Power BI dashboard to visually explore Netflix’s movies and TV shows dataset.  
The dashboard provides a consolidated view of Netflix content and enables users to examine patterns related to content type, release timeline, ratings, duration, genres, and country-wise availability through interactive visualizations.

---

## 🎯 Objectives of Exploratory Data Analysis Using Power BI Dashboard

- To perform exploratory data analysis on Netflix movies and TV shows using an interactive Power BI dashboard.  
- To analyze content distribution and trends based on type, release year, rating, duration, genre, and country.  
- To enable dynamic data exploration through visualizations, slicers, and filters.

---

## 📂 Dataset Description
- **Dataset Name:** netflix_titles.csv  
- **Total Records:** 8,800+ titles  
- **Content Types:** Movies and TV Shows  
- **Key Attributes:** show type, release year, rating, duration, listed_in (genre), country, and date added  

---

## 📊 Dashboard Features
- Movies vs TV Shows distribution  
- Content release trend by year  
- Titles added to Netflix over time  
- Rating-wise distribution of content  
- Country-wise content distribution (map)  
- Duration-wise distribution of content  
- Top 10 genres analysis  
- Interactive slicers for show type, release year, and country

---

## 💡 Key Insights

- Movies appear more frequently than TV shows in the dataset.  
- Netflix content releases increased notably after 2015, with peak values around 2019–2020.  
- TV-MA and TV-14 are the most commonly occurring ratings.  
- Most TV shows consist of a single season, while movie durations are commonly observed around 90–100 minutes.  
- Drama and international movie categories occur most frequently among listed genres.
